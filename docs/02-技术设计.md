# MyPaste 技术设计

> 状态：设计基线，尚未实现原生后端。当前交付为设计文档与浏览器 UI 原型；下述 Rust、SQLite、系统监听、托盘、全局快捷键和自动粘贴均属于后续实施方案。官方资料核对日期：2026-11-07。

## 1. 范围与默认约束

MyPaste 是 Windows 优先、未来扩展 macOS/Linux 的本地桌面剪贴板管理器。技术栈采用 Tauri 2、React、TypeScript、Vite 与 Tailwind CSS 4。首版记录纯文本、链接、图片和文件路径；文件拖放、富文本保真、OCR、云同步、账户和插件系统延后。

| 项目 | 默认值与语义 |
| --- | --- |
| 普通历史数量 | 500 条，不含收藏；按最近捕获时间淘汰 |
| 普通历史时长 | 30 天，从最近捕获时间计算；数量或时间任一条件触发即可淘汰 |
| 图片单张限制 | 标准化 PNG 不超过 10 MiB，同时限制解码内存与像素 |
| 图片总额 | 原图与缩略图实际文件字节合计不超过 500 MiB；收藏图片也计入 |
| 收藏 | 豁免数量和时间淘汰；不自动删收藏腾空间，磁盘上限提醒并拒绝新增图片 |
| 全局唤起键 | `Ctrl+Shift+V`，可改；注册失败明确提示冲突，不显示为已生效 |
| 回收站 | 软删后保留 7 天，仍占磁盘；恢复保留有效集合关系，彻底删除需确认 |
| 暂停 | 停止采集新历史，保留查询、复制、收藏和删除，不缓存待补录内容 |
| 浏览器原型 | 模拟数据，无系统监听、全局快捷键、托盘或原生自动粘贴 |

Windows 首批验证环境为 Windows 10/11 x64、WebView2 Evergreen；最低系统版本在打包阶段按所选 Tauri/WebView2 版本冻结。安装依赖时锁定稳定版本与 lockfile，不把文档中的主版本当作已经验证的组合。

## 2. 架构与职责

```text
React 页面 / 组件
  └─ ClipboardService（统一 TypeScript 接口）
       ├─ BrowserMockAdapter：模拟记录、状态、失败和设置
       └─ TauriAdapter：类型化 invoke + 受限事件订阅
            └─ Rust application services
                 ├─ CaptureCoordinator：采集状态、去重、自写回抑制
                 ├─ ClipboardPort：Windows / macOS / Linux 适配
                 ├─ Repository：SQLite、FTS、迁移与保留策略
                 ├─ ImageStore：标准化、缩略图、配额与文件回收
                 └─ DesktopService：快捷键、托盘、窗口、目标恢复与粘贴
```

Rust 是剪贴板、数据库、文件、快捷键与托盘的唯一所有者。React 不直接访问 SQLite、任意文件路径或剪贴板插件，也不把完整历史存入 localStorage。前端业务请求全部经服务接口；桌面适配器只调用本应用命令，事件用于失效通知和状态同步。平台插件可在 Rust 内部使用。

采用单进程单实例，第二次启动唤起已有窗口，避免多个监听器和数据库写入者。监听线程仅收通知并排队，有界队列合并同一系统版本通知；解码、哈希、数据库与文件操作在后台执行。SQLite 单写入工作队列、短读事务，设置 `foreign_keys=ON`、`journal_mode=WAL`、`busy_timeout=5000`。隐藏 UI 不停止采集；退出必须停止监听、注销快捷键并结束后台工作。


## 3. 数据模型、索引与搜索

数据保存在 Rust 获取的应用数据目录，例如 Windows `%LOCALAPPDATA%/<应用标识>/`，不依赖工作目录。下列为最初 v1 目标 schema；当前实际落地为 v6 schema（`items` 直接保存 PNG、缩略图、文件元数据、来源、使用次数与置顶，`collections` 含自定义排序 `position`），差异见 [原生接入说明](04-原生接入说明.md)：时间为 UTC 毫秒整数，SHA-256 为 64 位十六进制字符串。迁移按 `PRAGMA user_version` 顺序执行；失败停止写入，不自动重建丢失历史。

```sql
CREATE TABLE image_assets (
  id TEXT PRIMARY KEY,
  pixel_sha256 TEXT NOT NULL UNIQUE,
  relative_path TEXT NOT NULL UNIQUE,
  thumbnail_path TEXT NOT NULL UNIQUE,
  mime TEXT NOT NULL CHECK (mime = 'image/png'),
  width INTEGER NOT NULL CHECK (width > 0),
  height INTEGER NOT NULL CHECK (height > 0),
  original_bytes INTEGER NOT NULL CHECK (original_bytes > 0),
  thumbnail_bytes INTEGER NOT NULL CHECK (thumbnail_bytes >= 0),
  created_at INTEGER NOT NULL
);
CREATE TABLE clip_items (
  row_id INTEGER PRIMARY KEY,
  id TEXT NOT NULL UNIQUE,
  kind TEXT NOT NULL CHECK (kind IN ('text', 'link', 'image', 'file')),
  content_hash TEXT NOT NULL,
  title TEXT NOT NULL DEFAULT '' CHECK (length(title) <= 200),
  note TEXT NOT NULL DEFAULT '' CHECK (length(note) <= 10000),
  text_content TEXT,
  file_size_bytes INTEGER NOT NULL DEFAULT 0,
  file_modified_at INTEGER,
  file_entries_json TEXT,
  deleted_at INTEGER,
  image_asset_id TEXT REFERENCES image_assets(id) ON DELETE RESTRICT,
  source_app_id TEXT,
  source_app_name TEXT,
  first_captured_at INTEGER NOT NULL,
  last_captured_at INTEGER NOT NULL,
  last_used_at INTEGER,
  capture_count INTEGER NOT NULL DEFAULT 1 CHECK (capture_count > 0),
  favorite INTEGER NOT NULL DEFAULT 0 CHECK (favorite IN (0, 1)),
  CHECK (
    (kind IN ('text','link') AND text_content IS NOT NULL
      AND image_asset_id IS NULL)
    OR (kind = 'image' AND text_content IS NULL
      AND image_asset_id IS NOT NULL)
  ),
  UNIQUE(kind, content_hash)
);
CREATE INDEX idx_items_recent
  ON clip_items(last_captured_at DESC, id DESC);
CREATE INDEX idx_items_favorite_recent
  ON clip_items(favorite, last_captured_at DESC, id DESC);
CREATE INDEX idx_items_kind_recent
  ON clip_items(kind, last_captured_at DESC, id DESC);
CREATE INDEX idx_items_retention
  ON clip_items(last_captured_at, id) WHERE favorite = 0 AND deleted_at IS NULL;
CREATE INDEX idx_items_active_recent
  ON clip_items(last_captured_at DESC, id DESC) WHERE deleted_at IS NULL;
CREATE INDEX idx_items_trash ON clip_items(deleted_at DESC, id DESC)
  WHERE deleted_at IS NOT NULL;
CREATE INDEX idx_items_asset ON clip_items(image_asset_id);
CREATE TABLE collections (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL CHECK (length(trim(name)) BETWEEN 1 AND 80),
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
);
CREATE UNIQUE INDEX idx_collections_name ON collections(name COLLATE NOCASE);
CREATE TABLE item_collections (
  item_id TEXT NOT NULL REFERENCES clip_items(id) ON DELETE CASCADE,
  collection_id TEXT NOT NULL REFERENCES collections(id) ON DELETE CASCADE,
  PRIMARY KEY (item_id, collection_id)
);
CREATE INDEX idx_members_collection ON item_collections(collection_id, item_id);
CREATE TABLE settings (
  key TEXT PRIMARY KEY,
  value_json TEXT NOT NULL,
  updated_at INTEGER NOT NULL
);
CREATE VIRTUAL TABLE clip_fts USING fts5(
  title, text_content, note,
  content='clip_items',
  content_rowid='row_id',
  tokenize='unicode61'
);
CREATE TRIGGER clip_fts_ai AFTER INSERT ON clip_items BEGIN
  INSERT INTO clip_fts(rowid, title, text_content, note)
    VALUES (new.row_id, new.title, new.text_content, new.note);
END;
CREATE TRIGGER clip_fts_ad AFTER DELETE ON clip_items BEGIN
  INSERT INTO clip_fts(clip_fts, rowid, title, text_content, note)
    VALUES ('delete', old.row_id, old.title, old.text_content, old.note);
END;
CREATE TRIGGER clip_fts_au AFTER UPDATE ON clip_items BEGIN
  INSERT INTO clip_fts(clip_fts, rowid, title, text_content, note)
    VALUES ('delete', old.row_id, old.title, old.text_content, old.note);
  INSERT INTO clip_fts(rowid, title, text_content, note)
    VALUES (new.row_id, new.title, new.text_content, new.note);
END;
```

名称/备注编辑、收藏、去重、软删与 FTS 更新在同一事务中执行。`title` 为空时 UI 从正文或图片信息生成展示名，不修改正文；采集去重不能覆盖名称和备注。集合是多对多分类，删除集合硬删除分类及关系，不删除条目；回收站条目保留关系，恢复时仅剩仍存在的集合。集合名称先 trim，再按 SQLite NOCASE 保证 ASCII 忽略大小写唯一，不宣称完整 Unicode 等价。`settings` 仅允许 Rust 白名单与 schema 校验后的设置。来源字段描述最近一次捕获来源，允许为空；不存窗口标题，避免收集文档名。排除规则在读取正文前按规范化应用名匹配；来源识别失败时无法命中，因此排除不能视为可靠安全隔离。

FTS5 `unicode61` 没有中文分词，连续中文通常不会按词拆开，不能承诺任意中文词匹配。首版对名称 `title`、正文 `text_content`、备注 `note` 及关联集合名做参数化 `instr(..., :query) > 0` OR 查询，支持中文及任意字面子串；英文/空格分词可用转义、长度受限的 FTS 查询，FTS 不是必经通道。ASCII 大小写忽略通过受控转换实现，不宣称 SQLite 默认 `NOCASE` 覆盖全部 Unicode。名称/正文/备注 FTS 结果与集合名子串命中取并集，再与导航、类型、收藏和集合 ID 筛选取交集。图片搜索名称、备注、集合，不含 OCR。

`list_items` 必传 `scope: 'active' | 'trash'`，分别强制 `deleted_at IS NULL` / `IS NOT NULL`；不允许普通查询混入回收站。集合名查询用关联 EXISTS，避免多集合重复行。过滤后数量使用同一 WHERE 计算；回收站按 `(deleted_at DESC, id DESC)` 分页，普通列表按最近捕获分页，游标不能跨 scope 使用。空 query 不启用正文条件。集合改名/删除立即影响搜索，无需将集合名冗余存入 FTS。

不直接拼接用户输入，限制搜索词长度和页大小。普通列表排序固定为 `(last_captured_at DESC, id DESC)`，游标包含二元组与过滤摘要；变化事件触发首屏刷新。FTS 不优化 `instr` 子串扫描：默认 500 条可接受，但收藏无数量上限，必须测量 10,000 条性能，必要时评估 trigram 或中文分词扩展及其发行兼容性。索引、哈希同样属于敏感数据。

## 4. 命令与事件契约

Rust 定义 `serde` DTO，生成/校验相应 TypeScript 类型；仅 `invoke<T>` 泛型不能保证运行时类型，后续需契约集成测试。命令校验窗口身份、参数范围和 ID，不接受 SQL、任意文件路径或脚本。

```ts
type ClipKind = 'text' | 'link' | 'image' | 'file';
type CaptureState = 'running' | 'paused' | 'error';
type ClipSummary = {
  id: string; kind: ClipKind; title: string; preview: string; favorite: boolean;
  note: string; collectionIds: string[]; deletedAt: number | null;
  lastCapturedAt: number; sourceAppName: string | null;
  image: { width: number; height: number; thumbnailId: string } | null;
};
type AppError = {
  code: 'INVALID_ARGUMENT' | 'NOT_FOUND' | 'CLIPBOARD_BUSY'
    | 'STORAGE_FULL' | 'SHORTCUT_CONFLICT' | 'UNSUPPORTED'
    | 'TARGET_UNAVAILABLE' | 'INTERNAL';
  message: string; retryable: boolean;
};
type Reply<T> = { ok: true; data: T } | { ok: false; error: AppError };
type PasteOutcome = {
  copied: boolean;
  status: 'input_sent' | 'manual_required' | 'clipboard_failed';
  reason: string | null;
};
type CommandMap = {
  list_items: {
    args: { scope: 'active' | 'trash'; query: string;
      kind: ClipKind | null; favoritesOnly: boolean; collectionId: string | null;
      cursor: string | null; limit: number };
    result: { items: ClipSummary[]; total: number; nextCursor: string | null };
  };
  get_item: { args: { id: string }; result: ClipDetail };
  set_favorite: { args: { id: string; favorite: boolean }; result: ClipSummary };
  update_item_metadata: {
    args: { id: string; patch: { title?: string; note?: string } };
    result: ClipSummary;
  };
  list_collections: { args: Record<string, never>; result: Collection[] };
  create_collection: { args: { name: string }; result: Collection };
  rename_collection: { args: { id: string; name: string }; result: Collection };
  delete_collection: { args: { id: string }; result: { deleted: boolean } };
  set_item_collections: {
    args: { id: string; collectionIds: string[] }; result: ClipSummary;
  };
  trash_items: { args: { ids: string[] }; result: { trashed: number } };
  restore_items: {
    args: { ids: string[] }; result: { restored: number; retainedInTrash: number };
  };
  purge_items: { args: { ids: string[] }; result: { purged: number } };
  empty_trash: { args: Record<string, never>; result: { purged: number } };
  clear_history: { args: Record<string, never>; result: { trashed: number } };
  clear_local_data: {
    args: Record<string, never>; result: { purged: number; fileCleanupPending: boolean };
  };
  copy_item: { args: { id: string }; result: { copied: true } };
  paste_item: { args: { id: string }; result: PasteOutcome };
  get_settings: { args: Record<string, never>; result: Settings };
  update_settings: { args: { patch: SettingsPatch }; result: Settings };
  set_capture_state: { args: { paused: boolean }; result: RuntimeStatus };
  get_status: { args: Record<string, never>; result: RuntimeStatus };
};
type Collection = { id: string; name: string; activeCount: number };
// ClipDetail 为正文或图片元数据的可辨识联合；不暴露原始磁盘路径。
// Settings/SettingsPatch 为明确字段 DTO，禁止通用 Record 任意写设置。
// RuntimeStatus 包含采集状态、原因、配额、快捷键注册结果与平台能力。
```

`Settings` 至少包含 `maxItems=500`、`retentionDays=30`、`maxImageBytes=10485760`、`maxImageTotalBytes=524288000`、`shortcut='Ctrl+Shift+V'`、`theme='light'`（P1 扩展 dark/system）、`capturePaused=false`、`excludedApps=[]`（trim、忽略大小写与 `.exe` 后缀去重，最多 100 项、每项 120 字符）。数值有合理上下限且只能显式修改。`thumbnailId` 不是可拼接路径。条目额外记录 `lastUsedAt` 与 `useCount`，仅由成功写回剪贴板更新，用于“最常使用”排序。

元数据/收藏/集合修改、复制和粘贴只接受 active 条目；回收站可读详情、恢复、彻底删除，禁止直接复制。标题最大 200 字符、备注最大 10,000 字符、集合名 trim 后 1–80 字符；集合 ID 去重并验证全部存在，替换关系在同一事务完成。`clear_history` 仅软删 active 非收藏；`purge_items` 仅接受回收站 ID，`empty_trash` 清空回收站。彻底删除及清空本地数据在 UI 明示数量并确认；`clear_local_data` 是独立动作，先暂停采集，再删除所有条目、集合、资产及应用设置（当前会话保持暂停），清理失败文件须显式报告，不能误报完全移除。P0 可一次调用处理一个 ID，批量 UI 留待 P1。恢复不改正文或捕获时间；先按普通保留条件预检，超龄/容量外的非收藏留在回收站并计入 `retainedInTrash`，避免显示恢复成功后立即消失。收藏恢复不受数量/时长约束。所有幂等操作返回实际影响数，过期已彻底删除的 ID 返回 NOT_FOUND。

```ts

import { listen } from '@tauri-apps/api/event';
async function command<K extends keyof CommandMap>(
  name: K, args: CommandMap[K]['args'],

  return invoke(name, args);
}
type HistoryChanged = {
  revision: number;
  reason: 'capture' | 'favorite' | 'metadata' | 'collection'
    | 'trash' | 'restore' | 'purge' | 'retention';
  changedIds: string[];
};
const unlisten = await listen<HistoryChanged>('history://changed', () => {
  // 使当前查询失效并重新读取，不在事件中传递正文。

// 页面卸载调用 unlisten()；异步订阅晚于卸载完成也必须释放。
```

其他事件：`capture://status` 携带 `RuntimeStatus`，`storage://warning` 携带 `usedBytes/limitBytes/reason`，`shortcut://status` 携带生效快捷键和错误。只通知可信本地窗口，不广播正文。事件可能丢失/合并，不能作为唯一事实来源；前端先订阅再查询状态/列表，用单调 revision 检测缺口并重取，增加会话 ID 区分重启实例。事务提交后再发变化事件。Rust 错误映射稳定错误码，日志不带内容。

浏览器适配器实现相同服务接口，fixture 覆盖空列表、名称/备注/集合搜索、图片、收藏、软删恢复、暂停、配额与错误；重载默认重置演示历史，最多持久化非敏感主题/演示设置。真实复制可选：仅用户点击后尝试 `navigator.clipboard.writeText`，需要 HTTPS/localhost 安全上下文和授权，显示真实成功/失败；不轮询、不自动读取。粘贴按钮明确说明“原型无法向其他应用粘贴”，不显示虚假成功。

## 5. 监听、去重、自写回抑制与状态

### 5.1 Windows 采集

Rust 平台层创建消息窗口，使用 `AddClipboardFormatListener` 接收 `WM_CLIPBOARDUPDATE`，退出时移除监听；用 `GetClipboardSequenceNumber` 标识系统变化。通知本身不含内容。`tauri-plugin-clipboard-manager` 可以读写文本/图片，其官方 API 没有变化监听契约，不能把读写插件当监听器；必要时直接使用 Win32 读取格式并保持快照一致。

通知 → 检查状态/序列 → 约 50–100 ms 合并同版本通知 → 读取前台应用名并检查排除规则（命中则只更新基线，不读取正文）→ 有界重试读取 → 确认读前后序列一致 → 格式选择/限额 → 去重和事务 → 事件。剪贴板占用时短退避最多约 500 ms，新序列到达即放弃旧任务；失败不阻塞 UI。快速变化可能无法逐条捕获，产品不是完整审计日志。启动和恢复只建立当前序列基线，不自动补录现有内容。

快照中有有效图片则优先图片，否则取 Unicode 纯文本；HTML/RTF 仅取系统提供的纯文本版本，不执行或渲染。无支持格式跳过，只有文件列表格式不记录。正文里的路径仍按普通文本保存，不解析为文件访问资源。

### 5.2 去重规则

- 文本保留原始空白和换行，不 trim、不做 Unicode 归一化；空字符串跳过。建议单条 UTF-8 上限 1 MiB，超限拒绝并提示，不静默截断。
- 临时 trim 后整段能被 URL parser 识别为单一 `http/https` URL 时分类为链接，原文和哈希不改。其他协议作为文本；不请求 URL、不抓取标题/favicon。
- 文本哈希为 `SHA256(kind + 版本域分隔 + UTF-8 原文)`；图片基于规范 RGBA8 像素、宽高和版本域计算，相同像素不同编码可去重。变更转换规则需升级哈希版本。
- 唯一键覆盖 active 与 trash。冲突时核对实际内容，保留 ID、收藏、名称、备注和仍存在的集合，更新最近捕获、来源和次数。若命中软删条目，新一次外部复制视为重新采集：同一事务将 `deleted_at=NULL` 恢复并置顶，原整理信息不丢；UI 提示重新记录。这不是后台补录，暂停时仍不发生。已彻底删除则新建 ID。若真实哈希碰撞，拒绝本次并报无正文错误。应用历史复制只更新 `last_used_at`，不重置保留时钟。

### 5.3 自写回抑制

复制/粘贴命令经协调器串行执行。写之前登记短期 PendingWrite，含内部 token、目标哈希与单调时钟期限（初值约 1 秒），写成功记录系统序列和写入所有者线索。只有通知匹配可验证的本次写入序列/所有者及规范化内容时才消费抑制令牌。Windows 可用自控写入窗口/自定义剪贴板格式辅助关联，但其他应用可能剥离自定义格式。

不能仅按时间窗内相同哈希抑制，否则会吞掉用户真实复制。序列变化、超时或关联不可信时走正常去重，最多产生额外计数/置顶。写失败撤销令牌。通知可能早于写返回，必须先登记待写令牌、读后再校验，原生验证覆盖此竞争。

### 5.4 暂停与异常

`running → paused` 可由 UI/托盘触发并持久化，重启仍暂停。暂停完成是屏障：取消未提交采集、清空队列、事务前再次检查采集代次，保证命令返回后不再提交此前待处理内容。暂停时可更新序列基线，但不读取、解码或存正文。恢复更新代次和当前基线，不补录暂停期间内容。

`error` 表示监听初始化或存储持续失败，保留用户暂停意图，显式提示并提供重试，不静默恢复导致误采集。单图超限只跳过该条、发配额提醒，不永久停止文本采集。暂停只影响本应用历史，不能暂停系统剪贴板、Windows 历史或其他管理器。

## 6. 图片、一致性与保留

先校验尺寸与溢出，建议最大 20 百万像素、预计 RGBA 缓冲不超过 80 MiB；解码器须设置分配限制，不能任意大数据读完才判断。首版接收静态位图，转 PNG 并移除无用元数据，标准 PNG 不超过 10 MiB；若有编码输入，也要解码前限制输入大小。超限提示，不偷偷有损压缩。DIB/PNG、透明度和色彩空间须原生实测。资源管理器复制的文件使用 `CF_HDROP`：只解析 DROPFILES 中的路径列表，最多 500 项 / 1 MiB，不读取文件内容；对每个路径只做一次 `metadata` 读取，记录大小、修改时间与是否文件夹，文件夹不递归统计。复制时按同一列表写回 `CF_HDROP`，使其可粘贴到资源管理器。记录总大小达到 1 GiB 时在详情提示粘贴成本。

缩略图最长边建议 320 px，独立 PNG，纳入 500 MiB 配额。当前实现将缩略图作为独立 BLOB 存在 `items.thumb`（单张最多 512 KiB），大图仍通过 `get_image` 按需返回；列表缩略图仅在行接近视口时经 `get_thumbnail` 读取，不通过快照传输。文件名用内部 UUID、数据库存相对路径；Rust 固定根目录解析，防止 `..`、绝对路径及符号链接/重解析点逃逸。

数据库与文件系统无法跨介质原子提交，流程如下。

1. 原图/缩略图写同卷 staging，必要时同步后原子重命名；串行锁下预留新增字节。配额不足先拒绝，不为接收新图片而提前清除历史。
2. SQLite 事务插入资产和条目，失败回收未引用文件。软删只写 `deleted_at`，不删除资产、FTS 或集合关系。
3. 仅在回收站满 7 天或用户确认彻底删除后硬删除条目，再事务内移除未引用资产元数据，提交后删文件。失败进入待回收队列，未成功删除不能当成空间已释放。
4. 启动扫描临时文件、孤儿和缺失资产，按宽限期清理孤儿。缺图记录显示“图片文件缺失”并可删除。配额含孤儿/待删文件，定期对账。

保留任务在启动、采集成功后和每小时执行，使用同一写队列：将超 30 天的 active 非收藏软删，再将最新 500 条之外的 active 非收藏软删，`deleted_at` 写本次 UTC 毫秒。普通数量不计回收站；软删保留 7×24 小时，按 `deleted_at <= now - 604800000` 彻底删除，包括用户手动删入回收站的收藏。重复软删不重置截止时间。收藏切换触发保留检查，取消收藏可能立即进入回收站，应提示。恢复保留原有关系，已删除集合因级联关系移除不会复活。删除历史不修改系统剪贴板。

图片总额是独立硬限制，active、收藏和 7 天回收站都计费。新增按原图+缩略图增量计算，重复资产不重复计费；仅清理已经到期的回收站及可回收孤儿，仍不足或实际磁盘不足时拒绝新图片，文本可继续；提示用户检查回收站并主动彻底删除，不缩短 7 天期限。下调配额低于收藏占用时允许保存设置，但显示超额、阻止新增直至主动清理；不静默删收藏。磁盘检查预留安全余量，SQLite/WAL 满时回滚报告。

500 MiB 是图片预算，不是应用目录总上限：SQLite、FTS、WAL 和文本另占空间。设置页分别显示图片用量和目录估算总量，不能宣称整个应用永远只用 500 MiB。维护时做 WAL checkpoint，必要时显式压缩，不在每次采集执行 `VACUUM`。

## 7. 桌面交互与自动粘贴

快捷键由 Rust 的 Tauri global-shortcut 插件注册，默认 `Ctrl+Shift+V`，仅按下阶段触发。更改时验证并尝试新组合，成功后注销旧组合并持久化；失败保留旧键并提示冲突。启动注册失败仍可使用窗口/托盘；不能承诺该组合一定可用。

托盘菜单有打开、暂停/恢复、设置、退出。关闭窗口默认隐藏至托盘，首次提示；退出才结束监听。唤起前保存上一个外部前台窗口为本次粘贴候选，目标不可靠则为空。历史来源不等于粘贴目标。

主窗口 Enter 聚焦详情，不向外部输入；快捷窗口 Enter 复制并关闭，Ctrl+Enter 请求粘贴；快捷窗口支持类型/集合筛选与“最近复制/最常使用”排序，并在本次运行内记住上次选择。只完成复制但未发送输入时保持窗口打开并就地显示原因。可使用同一 main WebView 的窗口模式避免额外权限面；若后续独立 quick 窗口，必须单独授予最小 capability。Windows 自动粘贴为可选 best effort 能力。

1. 用户主动选择后，先把文本/位图写入剪贴板；失败保留窗口并报告，不能继续发键。
2. 验证目标句柄存在且不属本应用，隐藏面板，尝试恢复并确认实际前台窗口匹配；未知、焦点恢复失败或用户切换则停止，避免发错窗口。
3. 有界等待用户释放唤起键/修饰键后用 `SendInput` 发送 Ctrl+V 按下/释放。不能擅自提权，也不要求管理员运行。
4. `input_sent` 只表示系统接受完整输入事件数，不表示目标已插入内容；目标可能只读、覆盖快捷键或不接受图片。提示“已发送粘贴指令，若未生效请手动 Ctrl+V”。
5. `SendInput` 受 UIPI 限制，一般不能注入更高完整性级别应用，返回错误不能可靠归因 UIPI。失败返回 `manual_required`，保留复制内容，提示“已复制，请切回目标应用按 Ctrl+V”；无目标直接回退。

首版不逐字模拟输入、不自动重试、不恢复旧剪贴板、不向任意句柄强制注入。始终提供明确的复制操作。浏览器只演示状态，不触发系统输入。

来源识别通过剪贴板 owner 窗口、进程映射及变化时前台应用 best effort 采样。owner 可能为空、为代理或权限不可读；无法确认显示“未知来源”，不把前台猜测标成精确来源，不收集窗口标题。

## 8. 隐私、安全与 Tauri 权限

本地优先，无默认网络、遥测、云上传；链接不探测，内容以文本显示，禁止 `dangerouslySetInnerHTML`。首版在平台能识别系统敏感/排除标记时跳过，不保证识别所有密码/令牌；来源应用排除已在读取内容前实现，但来源识别失败时不生效，不能承诺零敏感记录。

默认 SQLite、FTS、图片、缩略图是当前用户目录里的明文。ACL 和系统磁盘加密可降低离线风险，但不能防同用户恶意程序、已解锁桌面和运行时内存读取；隐藏预览不是加密。FTS、WAL、临时文件、备份、截图和系统剪贴板均在隐私边界内。日志仅保留错误码、耗时与匿名计数，禁止正文、完整链接、图片和窗口标题。

未来加密需完整设计数据库/文件认证加密、密钥生命周期、锁定、迁移、恢复；只加密正文而留下 FTS/缩略图不是完整静态加密。DPAPI/钥匙串可保护密钥，但不防同登录用户上下文解密。SQL DELETE/文件删除仅为逻辑删除，不保证 SSD 安全擦除和备份销毁。

### 8.1 Capability 与 IPC

- 只给打包的本地 `main` 窗口必要命令与事件权限，不配置远程 URL capability，不在有权限 WebView 加载外站。未来打开外链须 Rust 校验 `http/https` 再经系统 opener。
- 前端不授予通用 fs/sql/shell/process/http/clipboard-manager/global-shortcut 权限。Rust 封装所有能力，capability 不能代替 Rust 参数和业务校验。
- Tauri 2 注册的自定义命令默认可由窗口调用；写 capability 不等于自动约束它们。后续用 `build.rs` 的 `AppManifest::commands(...)` 纳入应用命令权限，在 `permissions/` 定义授权并仅给 `main` 精确授予，按生成 schema 核对名称。
- 只启用必要 listen/unlisten，避免无必要的前端 emit；窗口身份从 Tauri 注入上下文读取，不信前端自报标签。

### 8.2 CSP 与图片暴露

发布 CSP 基线示意如下，须按实际协议和各 WebView 验证。Vite HMR localhost/ws 规则只进入开发 `devCsp`。

```text
default-src 'self';
script-src 'self';
style-src 'self';
img-src 'self' asset: http://asset.localhost blob:;
connect-src 'self' ipc: http://ipc.localhost;
font-src 'self';
object-src 'none';
base-uri 'self';
frame-src 'none';
```

不启用 `unsafe-eval`，不为调试将 CSP 设 null；优先外部样式/class，若构建需要内联样式则针对性核对。Tauri 处理必要 nonce/hash 不等于替应用制定策略。

优先采用资产 ID 到固定文件的受限图片协议。若用官方 asset protocol，scope 只允许应用图片子目录，禁止 `**/*` 或整个用户目录；CSP 和 scope 必须同时满足，URL 转换不是授权。自定义协议也须校验路径、来源、MIME、大小和错误响应，各平台协议源表示需实测。

## 11. 分阶段里程碑与可执行验收

### M0：设计与浏览器原型（当前范围）

- 模拟文本、链接、图片、中文长文、未知来源和空列表；名称/正文/备注/集合搜索及交集过滤、收藏、集合管理、重命名、备注、软删、恢复、彻底删除和设置可操作，刷新回到约定演示状态。回收站不允许直接复制。
- 点击暂停标注演示状态；在外部应用复制 10 次，原型不能新增记录或请求后台剪贴板读取。
- 默认展示 `Ctrl+Shift+V`、500 条、30 天、单图 10 MiB、总额 500 MiB；快捷键标明原型不能注册。
- 粘贴显示能力说明；若做真实文本复制，在 localhost 点击后人工粘到编辑器验证，拒绝授权显示失败。
- 键盘完成搜索、选择、收藏、关闭弹窗，焦点可见；窄窗口、125%/150% 缩放不裁主操作；`npm run build` 成功，无原生注入对象缺失错误。

### M1：Windows 原生探针（未来）

- 从记事本、浏览器、截图工具复制验证监听和格式；快速复制 100 次报告捕获率与丢弃，不承诺全捕获。
- 应用复制同条 20 次不新增；外部立即复制相同内容仍走正常去重计数。覆盖通知先后竞争、令牌过期、剪贴板占用。
- 暂停前制造队列，命令返回后无迟到写入；暂停复制秘密样例后恢复不补录，重启仍暂停。
- 注册已占组合失败并保留旧键；无快捷键仍能开窗口。关窗口继续采集，退出无残留快捷键/进程。
- 普通编辑器、管理员窗口、只读控件、目标关闭、修饰键未释放和焦点切换分别验自动粘贴/回退，失败不得发给其它窗口。

### M2：持久化与安全（未来）

- 新库/前版库迁移，核对版本、索引、FTS；错误停止写入且可恢复原库。
- 501 条 active 非收藏只保留最新 500，第 501 条进入回收站；31 天前非收藏软删，收藏保留。软删 6 天仍占配额，第 7 天到期硬删；收藏手动软删同样到期。验证恢复关系、集合删除级联、备注 FTS 更新、软删内容再采集保留元数据，以及普通/回收站搜索隔离。
- “剪贴板管理器”搜“管理”命中字面检索；引号/星号/SQL 符号无注入或异常。10,000 条含收藏样例测首屏 p95，参考设备目标 P95 小于 150 ms（不含输入防抖），记录硬件和文本分布。
- 10 MiB 边界、超像素、损坏图片和同像素不同编码验证；500 MiB 临界、收藏占满、实际磁盘不足不删收藏，文本继续。
- 在临时写入、重命名、数据库提交和文件删除失败点注入中断；重启孤儿可回收、缺图可见、配额不少计，FTS 与主表一致。
- 未授权窗口/远程页面/恶意路径调用被拒；检查发布 CSP、capability、日志和目录权限；HTML/脚本按纯文本展示。

### M3：打包与跨平台（未来）

干净 Windows 10/11 安装、离线重启、升级和卸载，验证 WebView2 依赖、托盘退出和迁移。在普通 4 核/8 GiB/SSD 参考机设热窗口可交互小于 500 ms、采集到首屏小于 500 ms 的目标（排除剪贴板占用与大图处理），公布测量方法后评定。macOS/Linux 先完成能力探针和权限/桌面环境矩阵，未通过前只列计划支持。

## 12. 待验证限制

1. Windows 延迟渲染、owner、DIB/PNG/透明通道和截图工具兼容；插件不足时 Win32 适配与内存限制。
2. 所选插件能否可靠获得自写回序列和所有者；不能关联则正常去重，不能扩大时间窗吞复制。
3. 焦点恢复、UIPI、输入法、目标编辑状态和图片粘贴兼容；发送成功不等于粘贴成功。
4. 稳定依赖组合、Rust MSRV、WebView2 基线、SQLite 构建 FTS5，以及发布包命令权限名/协议源表示。
5. 大量收藏的扫描性能与长期数据库占用；默认 500 条不约束收藏总量。
6. macOS/Linux 监听、来源、快捷键和粘贴需独立实现，尤其 Wayland 与辅助功能授权。
