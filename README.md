# MyPaste

参考 1Password 桌面端风格的本地剪贴板管理器，采用 **Tauri 2 + Rust + React + TypeScript + TailwindCSS 4**。当前包含 Windows 原生工程与浏览器演示两种运行模式。

## 启动 Windows 桌面版

需要 Node.js、Rust MSVC 工具链、Visual Studio C++ Build Tools、Windows SDK 和 WebView2。先安装前端依赖：

```bash
npm install
```

启动桌面开发模式（自动启动 Vite）：

```bash
npm run desktop:dev
```

请先关闭已经占用 1421 端口的浏览器开发预览，或直接使用嵌入前端的构建版本。

生成包含前端资源的调试版程序，不生成安装包：

```bash
npm run desktop:build -- --debug --no-bundle
```

产物：`src-tauri/target/debug/mypaste.exe`。首次编译需要下载 Rust 依赖；首次安装包构建可能还需要下载打包工具。

正式构建入口：

```bash
npm run desktop:build
```

## 两种运行模式

| 能力 | Tauri 桌面版 | 浏览器演示 |
| --- | --- | --- |
| 数据来源 | 本机 SQLite 和系统剪贴板 | 虚构示例 |
| 文本、链接、图片和文件记录 | Rust 后台采集 | 不监听 |
| 来源应用识别与排除 | 前台进程名；排除在读取内容前生效 | 演示来源与排除列表 |
| 图片缩略图 | 按需生成并缓存 | 虚构渐变图 |
| 复制记录 | Rust 写回系统剪贴板 | 仅文本/链接，需浏览器授权 |
| 复制为纯文本 | 原样 / 去首尾空白 / 合并单行 | 仅文本/链接 |
| 富文本回贴 | 随文本保存 HTML/RTF，可整体或按格式复制 | 演示 HTML，RTF 禁用 |
| 批量操作 | Ctrl/Shift 多选，批量收藏、置顶、加入集合、删除 | 演示状态 |
| 集合管理 | 重命名、删除（保留记录）、上下移排序 | 当前页面内保存 |
| 集合级保留 | 每个集合可覆盖保留天数与条数上限 | 演示设置 |
| 序列粘贴 | 多选后按顺序复制，全局快捷键推进并尽力粘贴 | 演示队列 |
| 开机自动启动 | 当前用户 Windows 启动项 | 禁用 |
| 管理员启动 | 显示权限并可请求提权重启 | 禁用 |
| 便携版 | exe 旁放 `portable.txt`，数据写入同目录 | 不支持 |
| 诊断日志 | 本地轮换日志，可打开目录或导出诊断 | 禁用 |
| 数据库维护 | 显示占用并可整理数据库 | 禁用 |
| 系统通知 | 快捷窗口复制/粘贴后通知 | 不支持 |
| 收藏、置顶、集合、名称和备注 | 本机持久化 | 当前页面内保存 |
| 删除、恢复、彻底删除 | SQLite 操作 | 演示状态 |
| 暂停和保留策略 | 本机持久化 | 不执行清理 |
| 备份导出/恢复 | SQLite 一致性快照 | 禁用 |
| 自定义存储路径 | 重启后迁移数据 | 禁用 |
| 托盘、关闭隐藏、单实例 | 原生功能 | 不支持 |
| 全局快捷键 | 默认 Ctrl+Shift+V，可修改，冲突可见 | 仅页面内 |
| Ctrl+Enter 自动粘贴 | Windows 尽力尝试，失败回退手动 Ctrl+V | 只复制并提示手动粘贴 |
| 自动更新 | 设置页检查、下载、签名校验并重启 | 不支持 |

桌面连接失败会显示错误，**不会回退为虚构记录**。列表读取摘要，完整正文、文件路径与图片按需读取；复制始终按记录 ID 执行，不复制被截断的摘要。文件记录只保存资源管理器给出的路径，不读取文件内容，复制后可粘贴回资源管理器。

### 日常操作

复制文本、链接、截图或文件后，记录自动出现。图片行显示按需加载的缩略图；文件记录显示总大小、每个文件的大小与修改时间，总大小达到 1 GB 会在详情提示粘贴成本。从浏览器或聊天软件复制图片时，即使剪贴板同时带有临时文件列表，也会保存为图片并显示缩略图；在资源管理器复制图片文件仍按文件记录保存路径，其中单个 PNG/JPEG/BMP 文件会显示缩略图，详情可按需预览。Ctrl+K 搜索；侧栏按类型筛选，工具栏按来源筛选；收藏用于长期保留，置顶让记录始终排在列表最前，集合用于分类，侧栏可管理集合的重命名、删除与排序。Ctrl/⌘ 点选或 Shift 连选记录后可用 Ctrl+A 全选，并批量收藏、置顶、加入集合或删除。详情可将文本或链接按原样、去首尾空白或合并为单行复制。从浏览器、Word 等应用复制的富文本会同时保存 HTML/RTF；“复制为”可只写回 HTML 或 RTF，粘贴到 Word 等编辑器时保留排版。名称和备注失焦后保存，失败草稿在当前运行会话中保留，可切回记录重试。

多选后点击“序列粘贴”可按选择顺序连续填写多个字段：首条立即复制，之后每次按全局快捷键复制并尽力粘贴下一条；序列进行中呼出快捷窗口不会误推进，主窗口可查看进度、手动复制下一项或结束。集合管理里可为每个集合单独设置保留天数与条数上限，留空跟随全局；记录只要仍被任一集合保留，就不会被清理。

Ctrl+Shift+V 呼出独立的快捷窗口，上下键选择，Enter 复制，Ctrl+Enter 请求粘贴，Esc 关闭。快捷窗口可按类型和集合过滤，排序入口在结果标题右侧，可切换“最近复制/最常使用”（置顶记录优先）；只复制但未发送输入时窗口保持打开并显示原因。全局快捷键只显示这个快捷窗口（无边框、置顶、失焦自动隐藏），不会带出主窗口；在主界面点击打开的快捷窗口仍是页内浮层，关闭后返回主界面。窗口隐藏后完成复制或自动粘贴时，会用系统通知确认结果。

关闭主窗口后程序仍在托盘运行；从托盘菜单选择“退出”才停止采集。需要临时停止采集时使用侧栏或托盘的暂停功能，暂停状态重启后保留。

### 数据和隐私

- 默认使用操作系统应用数据目录，可在设置“数据”页查看、打开文件夹或迁移到其他绝对路径；迁移在应用重启后、数据库打开前完成，复制成功才删除旧文件。
- 设置“数据”页可导出包含全部记录与图片的 `.sqlite3` 备份，也可从备份恢复；恢复会替换全部记录与集合，快捷键、保留策略与排除应用等本机设置保持不变。
- 设置“数据”页显示数据库占用（含 WAL 边车文件）与记录数，并提供“整理数据库”；设置“通用”页可开启登录后自动启动。
- 无账号，默认不上传剪贴内容。来源应用名称可能不可用；详情中的“排除此应用”或设置“隐私”页可让该来源的新内容在读取前被跳过。来源识别失败时排除规则不生效。
- 本地数据库不等同于加密保险箱。处理密码或密钥前请暂停；系统敏感标记无法覆盖所有应用。
- 默认普通历史 500 条 / 30 天，收藏与置顶豁免条数和时间限制；集合可单独覆盖，受管集合成员按集合策略保留。
- 便携版：把 `portable.txt` 放在 exe 同目录（或运行 `npm run portable:package`），数据写入同目录 `data/`，WebView2 缓存写入 `webview2/`，设置页不能更改存储位置。
- 设置“通用”显示当前权限，可请求以管理员身份重启；设置“数据”可打开诊断日志目录或导出诊断文本，日志不含剪贴板正文、搜索词或窗口标题。
- 单条文本最多 1 MiB，图片单张 10 MiB、总计 500 MiB；文件记录采集时只保存路径与大小/修改时间快照，单条最多 500 项 / 1 MiB；单个 PNG/JPEG/BMP 文件的缩略图与详情预览会按需读取该文件（≤10 MiB）；回收站保留 7 天并仍占空间。
- 删除只移除应用持有的数据，不保证 SSD、系统备份或其他剪贴板工具中的副本不可恢复。

实际实现与最初设计的差异、原生命令和验收边界见 [原生接入说明](docs/04-原生接入说明.md)。

## 版本、自动打包与更新

仓库由 Git 管理，远程地址为 <https://github.com/yixin8875/mypaste>。每次用户可见改动记录在 [CHANGELOG.md](CHANGELOG.md) 的 `[Unreleased]`，发布时移入版本小节。

- 推送 `main`：GitHub Actions 运行测试并构建 Windows NSIS 安装包，作为 Actions 产物保留。
- 推送 `v*` 标签：签名构建安装包与更新包，创建 GitHub Release 并上传 `latest.json`。
- 安装版可在设置 → 通用检查更新；更新包通过 Minisign 公钥校验，签名不符时拒绝安装。

签名私钥只保存在本机，不进入仓库。密钥配置、版本号与发布步骤见 [版本与发布](docs/05-版本与发布.md)。

## 验证

前端回归测试：

```bash
npm test
```

Rust 测试：

```bash
npm run test:rust
```

前端类型检查和生产构建：

```bash
npm run build
```

构建嵌入前端的调试版后，可以运行真实桌面 IPC 与重启验收：

```bash
npm run test:native
```

该脚本仅适用于 Windows 调试构建，使用独立 `.native-smoke-*` 数据目录，通过本机 WebView2 调试端口验证。脚本不会读写系统剪贴板内容，不能替代真实采集、快捷键和目标应用粘贴的人工验收。测试结果保存为 `docs/native-smoke-result.json`。

P2B 隔离验收（集合策略、诊断、序列安全路径、便携模式）：

```bash
npm run test:native:p2b
```

结果保存为 `docs/native-p2b-result.json`。真实序列粘贴、管理员重启 UAC 与老化过期清理仍需人工验收；拖到外部应用本期未实现。便携打包自测与生成：

```bash
npm run test:portable
```

```bash
npm run portable:package
```
