# MyPaste 产品需求文档

版本：0.1 设计稿 · 2026-11-07

## 产品定位

MyPaste 是本地优先的桌面剪贴板管理器，帮助经常在浏览器、编辑器、聊天软件间切换的人找回复制过的内容，并整理重复使用的素材。首版 Windows 优先，无需账号；未来扩展 macOS/Linux。核心任务：记录、找回、复用。

## 场景与优先级

| 场景 | 任务 | 首版行为 |
| --- | --- | --- |
| 复制新内容覆盖旧内容 | 找回历史文本 | 时间列表、搜索、预览、复制 |
| 开发和写作重复使用素材 | 建立常用片段库 | 收藏、集合、重命名、备注 |
| 收集截图和链接 | 快速判断内容 | 图片预览、链接文本预览 |
| 处理隐私资料 | 停止采集和清理 | 暂停、删除、回收站、彻底删除 |

P0：纯文本/HTTP(S)链接/图片/文件路径采集、HTML/RTF 富文本采集与按格式回贴、内容去重、搜索、类型/来源筛选、来源应用排除、收藏、置顶、集合与集合管理、详情、复制与复制为纯文本、列表多选与批量操作、序列粘贴、按集合配置保留策略、图片缩略图、快捷窗口筛选与排序（跟随当前显示器）、托盘、暂停、保留策略、回收站、本地备份与恢复、可修改存储路径、开机自动启动、管理员启动、便携版、数据库占用与整理、诊断日志、系统通知、签名自动更新。

P1：深色主题。来源应用识别尽力提供，未知不阻塞采集；识别失败时无法应用排除规则。

后续：拖到外部应用（需要 OLE `IDataObject`/`IDropSource` 与 WebView 拖动会话集成，本期暂缓）、OCR、云同步、端到端加密同步、文件内容预览与管理、团队共享。首版不包括这些能力，也不显示虚假的已开通状态。

## 信息架构

```text
主窗口
├─ 全部记录 / 收藏
├─ 类型：文本 / 链接 / 图片 / 文件
├─ 我的集合
├─ 最近删除
├─ 暂停 / 恢复记录
└─ 设置：通用 / 历史保留 / 数据 / 隐私
快捷窗口
└─ 搜索 → 选择 → 复制或请求粘贴
```

收藏表示长期保留，置顶表示在列表中始终靠前且同样豁免清理；集合表示分类，一个条目可以属于多个集合，集合可重命名、删除与上下移排序，删除集合不删除记录。删除进入最近删除，7 天后自动清理；恢复时恢复原有关系，已删除的集合除外。

本地数据默认存放在应用数据目录，可在设置“数据”页改为任意绝对路径；更换后应用重启并在数据库未打开时迁移现有 `history.sqlite3`，复制全部成功后才删除旧文件。备份导出单个 `.sqlite3` 快照（含图片、缩略图与 HTML/RTF 富文本），恢复时替换全部记录与集合、保留本机设置。

集合可单独设置保留天数与条数上限，留空跟随全局。集合策略只作用于该集合；集合内记录只要仍被任一集合保留，就不会按时间或全局条数清理。收藏与置顶始终豁免。

序列粘贴用于连续填写多个字段：在列表中多选后选择“序列粘贴”，按选择顺序开始，首条立即复制；之后每次按全局快捷键复制并尽力粘贴下一条到前台应用。快捷窗口打开时不推进序列，仍可正常呼出；主窗口显示进度，可手动“下一项”或结束，10 分钟无操作自动结束。一次最多 200 条，回收站记录需先恢复。

可执行文件旁存在 `portable.txt` 时启用便携模式：数据写入同目录 `data/`，WebView2 缓存写入同目录 `webview2/`，忽略并禁止修改存储位置。设置“通用”显示当前是否以管理员身份运行，并可请求以管理员身份重启（UAC）；不会创建登录时自动提权的计划任务。诊断日志写入数据目录 `logs/mypaste.log`，达到 1 MiB 轮换并保留最近 3 个历史文件；只记录运行事件与错误，不记录剪贴板内容、搜索词或窗口标题。设置“数据”页可打开日志目录或导出诊断文本。

## 核心流程

### 自动记录

剪贴板变化 → 判断暂停/来源排除/敏感标记/类型/大小 → 读取 → 指纹去重 → 持久化 → 更新列表。来源排除在读取内容之前判断，命中时不读取正文；相同内容更新最后复制时间、来源与次数，不覆盖用户名称和备注。若剪贴板同时提供 CF_HTML 或 RTF，会与纯文本一并保存；之后再次复制同一纯文本不会抹掉已保存的格式。系统敏感标记在能够识别时跳过，不能承诺识别所有密码。

### 找回并复用

主窗口或快捷键呼出 → 搜索 → 类型/来源/集合筛选 → 选择 → 预览 → 复制。主窗口 Enter 聚焦详情，不自动向其他窗口输入。快捷键只弹出独立的快捷窗口，不显示主窗口。快捷窗口在该快捷键按下的前台窗口所在显示器居中弹出，可切换“最近复制/最常使用”排序（置顶记录始终优先），并在本次运行内记住上次的类型与集合筛选；Enter 复制并关闭，Ctrl+Enter 尝试粘贴到原窗口。只完成复制但未能发送输入时，快捷窗口保持打开并就地提示“已复制，请在目标应用按 Ctrl+V”。

### 整理与删除

详情支持重命名、备注、收藏、置顶、加入集合，以及把文本/链接按原样、去首尾空白或合并为单行复制。记录带有 HTML/RTF 时，默认复制写回纯文本与全部可用富文本格式；“复制为”也可只写回 HTML 或 RTF，缺少所选格式时明确报错，不伪造内容。列表支持 Ctrl/⌘ 点选、Shift 连选与 Ctrl+A 全选，可批量收藏、置顶、加入集合或移到最近删除。正文保留采集快照，修改正文另建条目延后实现。删除可恢复，彻底删除需确认并显示数量；清空普通历史保留收藏，清除全部本地数据为独立操作。

## 默认策略

| 项目 | 默认值与边界 |
| --- | --- |
| 普通历史 | 最多 500 条、最长 30 天，任一先到即清理 |
| 集合策略 | 每个集合可覆盖为 7/30/90/365 天与 100/500/1,000/5,000 条，留空跟随全局；多集合归属时任一集合保留即保留 |
| 收藏 / 置顶 | 豁免条数和时间限制，仍受磁盘容量约束 |
| 本地存储 | 默认应用数据目录，可改为任意绝对路径；迁移在重启后、数据库打开前完成 |
| 备份 | 导出单个 SQLite 快照；恢复替换全部记录与集合，保留快捷键、保留策略与排除应用 |
| 图片 | 单张最多 10 MiB，图片文件总计 500 MiB |
| 图片空间不足 | 停止新增图片并提示，不静默删除收藏 |
| 文本 | 单条最多 1 MiB，超限跳过并提示 |
| 富文本 | HTML/RTF 各最多 1 MiB；超限或格式无效时保留纯文本，不阻断采集 |
| 文件 | 采集时只保存路径与大小/修改时间快照，不读取文件内容；单个 PNG/JPEG/BMP 文件的缩略图与详情预览按需读取；文件夹不递归统计；单条最多 500 项或 1 MiB 路径 |
| 回收站 | 保留 7 天，仍占磁盘空间 |
| 暂停 | 持久化暂停状态，重启后不自动恢复采集 |
| 关闭窗口 | 隐藏至托盘，托盘“退出”停止进程 |
| 序列粘贴 | 一次最多 200 条、10 分钟无操作自动结束；首条立即复制，之后由全局快捷键推进 |
| 便携模式 | 检测到 exe 同目录 `portable.txt` 时启用；数据在 `data/`，缓存 `webview2/`，不能更改存储位置 |
| 诊断日志 | `logs/mypaste.log` 达到 1 MiB 轮换，保留 3 个；不记录剪贴板正文、搜索词或窗口标题 |

无账号、默认不上传。首版数据库不承诺静态加密，不等同于密码保险箱。彻底删除指应用数据移除，不保证 SSD、备份、其他软件历史中的副本不可恢复。

## 交互规则

- 搜索名称、正文、备注和集合名称；图片只搜索名称/备注/集合，不含 OCR。
- 搜索、导航、类型、来源与集合过滤取交集，数量展示过滤后的结果。
- 来源应用可显示为“未知来源”；用户可在详情排除当前来源，或在设置中手动添加。排除只阻止新增，不影响已有记录查看与删除。
- 图片行按需加载缩略图；缩略图读取失败时回退为类型图标，不阻塞列表。
- 当前项被过滤或删除时选第一条；无结果显示空态并提供清除搜索。
- 最近删除与普通搜索隔离，不能从回收站直接复制，需先恢复。
- 暂停仅停止新增采集，不影响历史查看与复制。
- 预览不加载链接页面；只有显式操作才允许打开 HTTP(S) 地址。
- 长文本和链接换行；代码等宽字体；图片保持比例。
- 图标按钮带名称和提示，所有操作支持可见焦点，弹层关闭恢复焦点。
- 序列粘贴开始时清空当前多选并显示进度条；推进失败或超时结束时给出提示，不静默停止。
- 集合策略在“管理集合”中按集合编辑；恢复记录时，属于受管集合的记录不按全局条数/时间再次拦截。
- 便携模式与管理员状态只读展示；以管理员身份重启前需确认，取消 UAC 时应用继续以当前权限运行。
- 诊断导出只含版本、系统、路径、设置摘要、计数与最近日志，不含剪贴板正文、搜索词、窗口标题或集合名称。

## 状态文案

| 状态 | 文案与动作 |
| --- | --- |
| 首次使用 | 复制一段内容，从这里开始。 |
| 搜索无结果 | 没有找到相关记录。清空搜索 |
| 空集合 | 这个集合还没有内容。从记录详情加入内容 |
| 暂停 | 记录已暂停。恢复记录 |
| 复制成功 | 已复制到剪贴板 |
| 复制失败 | 复制失败，请重试或手动选取内容 |
| 快捷键占用 | 快捷键已被占用，请换一个组合 |
| 保存失败 | 无法保存记录，请检查磁盘空间或目录权限 |

## 验收标准

1. 复制 10 条不同文本后均能找回；重复复制只更新一条。
2. 文本、链接、图片与文件路径正确展示；图片列表显示缩略图；文件显示大小与修改时间，总大小达到 1 GB 时提示粘贴成本；超限不阻塞 UI。
3. 搜索/类型/来源/集合交集正确；回收站与普通结果隔离。
4. 排除应用后，来自该应用的新复制内容不新增记录，且不读取其正文；解除排除后恢复采集。
5. 快捷窗口类型/集合筛选与排序结果正确，置顶优先，并在前台窗口所在显示器弹出；未发送输入时保持打开并显示原因。
6. 收藏、置顶、集合、备注重启保留；删除后可恢复。
6a. 导出备份后可在另一份数据上恢复出相同记录、集合、置顶与图片；非法或版本过新的备份被拒绝且不改动当前数据。
6b. 更改存储路径后应用重启并从新目录读取原有记录；目标目录已有数据时拒绝迁移并保留原数据。
6c. 为集合设置更长的保留时间或独立条数上限后，该集合的记录按集合策略保留；清空策略后重新跟随全局；收藏与置顶不受影响。
6d. 多选开始序列粘贴后，首条进入剪贴板；每次按全局快捷键复制并粘贴下一条；快捷窗口打开时不推进；主窗口可手动推进与结束。
6e. 可执行文件同目录放置 `portable.txt` 后，数据与日志写入同目录 `data/`，设置页不能更改存储位置；移除标记后恢复系统数据目录。
6f. 设置页显示管理员状态并可请求提权重启；诊断目录可打开，导出的文本不含剪贴板正文、搜索词或窗口标题。
7. 暂停后不新增，重启保持暂停状态。
8. 自己写回剪贴板不会重复记录；错误不冒充成功。
9. 快捷键冲突可见且可更改。
10. 键盘能完成搜索、选择和复制，焦点可见。
11. 性能目标：10,000 条基准数据，热窗口可交互 < 500ms、搜索 P95 < 150ms；属于待测目标，不是当前测量结果。

## 当前交付边界

Windows 桌面版已接入真实剪贴板监听、SQLite、托盘、全局快捷键、自动粘贴、文件记录、来源应用排除、快捷窗口筛选与多屏定位、置顶、集合管理、集合级保留策略、列表多选与批量操作、复制为纯文本、HTML/RTF 富文本采集与按格式回贴、序列粘贴、本地备份/恢复、可配置存储路径、开机自动启动、管理员重启、便携模式、数据库占用与整理、诊断日志、系统通知、图片缩略图与签名自动更新。浏览器模式仍是使用虚构数据的交互原型，不监听剪贴板，也不连接桌面数据库。

暂缓：拖到外部应用。实现需要在 WebView 中接管原生拖动会话并提供 OLE `IDataObject`/`IDropSource`，还要按条目类型分别构造文本、HTML、位图与 `CF_HDROP` 数据；当前自动化环境无法验证跨应用投放，且真实拖动会触碰用户剪贴板与文件系统，故本期不提供该入口，也不以“可拖动”样式误导用户。

自动打包与发布由 GitHub Actions 承担：推送 `main` 生成安装包产物，推送 `v*` 标签创建带 `latest.json` 的 Release。更新下载与安装仍需在真实安装版上人工验收。

自动化测试不读写真实剪贴板，不能替代人工验收；真实采集、来源识别、排除规则、快捷键、目标应用粘贴和高 DPI 表现仍需在 Windows 上人工确认。安装包与跨平台支持尚未验收。

待实施前确认：最终名称、商业授权、macOS 优先级。当前以 MyPaste、本地个人使用、Windows 优先作为设计假设。
