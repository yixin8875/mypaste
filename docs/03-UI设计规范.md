# MyPaste UI 设计规范

版本 0.1 · 2026-11-07。参考用户提供的 1Password Windows 截图；采用独立 MyPaste 标识和虚构内容，不使用 1Password 品牌素材。

## 设计方向

保留参考图的桌面秩序：浅灰导航、窄列表、宽详情、细分隔线与克制蓝色。将保险库语义替换为剪贴板历史和个人素材库；右栏直接阅读正文。所有内容主要左对齐，图标辅助扫描，不使用营销式卡片墙。

## 布局尺寸

常规桌面：导航 216px、列表 330px、详情自适应，详情内容最大 810px。顶部 52px，底部提示 32px，各列独立滚动。列表行最小 72px，导航项 36px，整体保持紧凑。

≥1550px：导航 232px、列表 360px。≤1150px：导航 204px、列表 310px。≤950px：侧栏转抽屉。≤680px：列表和详情上下排列，供浏览器窄预览检查，不代表移动 App 规划。

正式桌面窗口建议默认 1360×900、最小 960×640；需按真实 DPI 测试。

## 组件与交互

### 导航和列表

导航分全部记录、收藏、类型、集合、回收站，计数来自演示数据。集合支持新建、加入、移除；原型不包括集合删除排序。侧栏不设“个人空间”卡片，品牌区下方直接进入导航，以节省纵向空间。侧栏与快捷窗口的品牌标识使用与托盘、应用图标相同的方形图标（#2F63DD 底、白色竖版矩形），不加额外描边或圆角。

列表按今天/昨天分组。行显示图标、名称、单行摘要、来源和时间；选中背景浅蓝并带蓝色侧标，收藏有星标。图片行在图标位置显示按需加载的缩略图，读取失败时回退为图片图标。工具栏提供类型与来源两个下拉筛选，与搜索、集合筛选取交集。当前项不可见时展示第一条；无结果有空态和清除筛选入口。上下键移动选择。

### 内容详情

顶部显示预览类型、收藏和删除。正文区显示名称、来源、时间、预览与复制。来源行提供“排除此应用”，点击后把该来源加入排除列表；未知来源不显示该操作。下方可修改名称、备注和集合关联；正文保留采集快照。

文本保留换行，代码使用等宽字体。链接不联网抓取标题/favicon，只有显式按钮触发外部 HTTP(S) 导航。图片保持比例，原型图景由 CSS 绘制，为虚构素材。文件记录显示文件名与完整路径；单个 PNG/JPEG/BMP 文件可按需读取生成缩略图与详情预览，其余文件不读取内容。复制按钮写回文件列表，可粘贴到资源管理器。

回收站用恢复和彻底删除代替复制动作，彻底删除二次确认；恢复后保留收藏和集合关系。

### 快捷窗口

桌面版为独立无边框窗口，约 640×610，置顶、不进任务栏，失焦或 Esc 隐藏；浏览器原型仍使用居中浮层。快捷窗口只渲染选择面板本身，不显示侧栏、列表或详情。

```text
┌─────────────────────────────────────┐
│ MyPaste                             │
│ 搜索文字、链接、灵感…          Esc  │
├─────────────────────────────────────┤
│ 全部 文本 链接 图片 文件  最近复制▾ │
│ 所有集合▾                           │
│ 未发送输入时的原因提示              │
├─────────────────────────────────────┤
│ 最近复制                            │
│ 缩略图/图标  记录名称          ↵复制 │
│ 缩略图/图标  记录名称                │
│ 缩略图/图标  记录名称                │
├─────────────────────────────────────┤
│ ↑↓ 选择   ↵ 复制   Ctrl↵ 粘贴       │
└─────────────────────────────────────┘
```

Ctrl+Shift+V 呼出（浏览器内为页面快捷键，桌面版为全局快捷键），上下键选择，Enter 复制并关闭，Escape 关闭。类型标签与集合下拉可缩小范围；排序按钮在“最近复制/最常使用”间切换，后者按使用次数、最近使用时间排序，并在本次运行内记住上次筛选与排序。Ctrl+Enter 尝试粘贴；只完成复制但未发送输入时，窗口保持打开并在结果上方就地显示原因。不能把发送按键当作粘贴成功。

### 设置

通用、历史保留、隐私三个页签。通用解释快捷键与暂停，历史保留演示时间/条数选择，隐私页说明本地存储边界并提供排除应用列表：可输入应用名添加，或点选已排除项移除。排除项在读取剪贴内容前生效；来源识别失败时无法匹配。浏览器演示只修改当前页面状态，不执行清理。深色模式为后续 P1，当前交付浅色主题。

## 状态与可访问性

提供搜索空态、空详情、暂停、复制成功/失败、删除/恢复和彻底删除确认。图标操作有 aria-label/title，可见蓝色焦点；弹层限制 Tab 焦点、支持 Esc、关闭恢复焦点；反馈使用 status live region；尊重 prefers-reduced-motion，无自动循环动画。

原生阶段还需验证读屏顺序、Windows 高对比度、高 DPI、200% 缩放、真实监听失败、配额耗尽、快捷键冲突。

## 当前交付边界

浏览器演示可交互：搜索、类型/来源筛选、条目切换、文本/链接复制、收藏、新建集合、集合关联、名称/备注、删除/恢复/彻底删除、暂停状态、设置、排除应用列表、快捷窗口筛选/排序与缩略图占位。

Windows 桌面版已实现系统监听、托盘、全局快捷键、尽力粘贴、SQLite 持久化、自动清理、真实图片与文件读写、缩略图与来源排除；安装包和跨平台支持尚未验收。浏览器模式刷新后恢复虚构数据，且图片与文件复制会明确提示需使用桌面版。
